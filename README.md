# APEX MOTORWORKS — Премиальный Автомобильный Экспириенс

Инженерный цифровой опыт современного автосервиса высшего класса. Проект создан с кинематографическим подходом: интерактивная 3D-разборка автомобиля, синхронизированная со скроллом, физически корректные PBR-материалы, технические векторные чертежи узлов и фокус на прямом телефонном звонке клиента.

---

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`.

### 3. Сборка для продакшена
```bash
npm run build
```
Готовые оптимизированные статические файлы будут скомпилированы в директорию `dist/`.

---

## 🛠 Где менять данные автосервиса (Кастомизация)

Все контактные данные, название автосервиса, адрес, график работы, каталог услуг и параметры оборудования вынесены в **один центральный файл конфигурации**:

📁 **`src/config/siteConfig.ts`**

### 1. Название и слоган
```typescript
brandName: 'APEX MOTORWORKS', // Замените на название вашего автосервиса
tagline: 'Инженерный центр обслуживания и ремонта автомобилей',
```

### 2. Телефон, адрес и часы работы
```typescript
contacts: {
  phoneDisplay: '+7 (495) 822-09-90',   // Текст на кнопках и в шапке
  phoneHref: 'tel:+74958220990',         // Номер для прямого вызова с телефона
  address: 'Москва, ул. Автозаводская, 23, корп. 7',
  workingHours: 'Пн — Вс: 09:00 — 21:00 (без выходных)',
  navigationUrl: 'https://yandex.ru/maps/?rtext=~55.7058,37.6432&rtt=auto',
}
```

### 3. Услуги и регламенты
В массиве `services` в том же файле можно легко отредактировать названия, описания, симптомы поломок и используемое оборудование для каждой услуги.

### 4. Оборудование и боксы
В объекте `workshopSpecs` можно указать реальные марки ваших подъемников, 3D-стендов сход-развала и диагностических сканеров.

## 🎨 Используемые библиотеки и технологии

- **Three.js**: Процедурная модульная 3D-модель автомобиля из 10+ механических узлов, окружение студии `RoomEnvironment`, PBR-материалы `MeshPhysicalMaterial` с лаковым покрытием (clearcoat) и анизотропным отражением металла.
- **GSAP + ScrollTrigger**: Плавная кинематическая разборка автомобиля при прокрутке страницы вниз и обратная сборка при скролле вверх.
- **Tailwind CSS v4**: Высокоточная темная эстетика, типографика (Barlow Condensed, Plus Jakarta Sans, Space Mono) и адаптивная сетка.
- **Lucide React**: Лаконичные технические иконки.

## ⚙️ Архитектурные особенности

1. **Честная 3D-разборка без тяжелых внешних файлов**:
   Автомобиль процедурно собирается в Three.js. Отсутствуют внешние сетевые зависимости или медленно загружающиеся `.glb` файлы, гарантируя мгновенный запуск и стабильные 60 FPS на десктопах и смартфонах.
2. **Интерактивная панель инспекции (Bottom Dock)**:
   Пользователь может в любой момент вручную вращать автомобиль на 360°, переключать ракурсы камеры («В сборе», «Разборка», «Двигатель», «Тормоза») или регулировать степень разделения узлов ползунком.
3. **Строгая политика прямых звонков (No-Form Policy)**:
   На сайте намеренно отсутствуют формы сбора лидов, скрытые поля ввода или фальшивые чаты. Все кнопки вызывают мгновенный переход к набору номера мастера через ссылку `tel:`.
